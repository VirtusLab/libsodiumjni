# Agent skills (libsodiumjni)

This directory holds **agent skills**: task-specific guidance loaded on demand by AI coding agents. Each
subdirectory contains a `SKILL.md` with frontmatter and instructions (see
[agentskills/agentskills](https://github.com/agentskills/agentskills) for the open standard). `.claude/skills` links
here.

## Skills

| Skill | Scope |
|-------|-------|
| [adding-libsodium-methods](./adding-libsodium-methods/SKILL.md) | New / changed native methods, C code conventions |
| [adding-a-platform](./adding-a-platform/SKILL.md) | New OS / CPU architecture support |
| [linux-docker-testing](./linux-docker-testing/SKILL.md) | Testing on Linux from macOS, what can't be tested locally |
